# Qless

**Smart Campus Canteen & Food-Waste Optimisation Platform**
*Less Waiting. Less Waste. Better Campus.*

Stack: Python Flask, MySQL, Jinja templates, vanilla JavaScript,
Pandas / NumPy, Chart.js, Matplotlib.

## Run locally

1. Create a virtual environment: `python -m venv venv`
2. Activate it, then run: `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and fill in your values
4. Start the server: `python app.py`
